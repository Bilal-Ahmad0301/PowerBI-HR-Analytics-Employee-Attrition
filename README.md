PowerBI-HR-Analytics-Employee-Attrition

HR Analytics dashboard built with Power BI to analyze employee attrition and workforce trends.

📊 Project Overview

This project is an HR Analytics dashboard created using Microsoft Power BI. The purpose of this project is to analyze employee data and identify patterns and factors related to employee attrition.

The dashboard provides an interactive overview of employee demographics, attrition, salary, job roles, education, and years at the company.

💡 Key Insights
The overall attrition rate in the dataset is 16.12%, with 237 out of 1,470 employees having left the company.
Attrition is analyzed across multiple employee and job-related factors — including age, salary, education, job role, and tenure — to identify which groups are most at risk of turnover.
These patterns can help HR teams prioritize retention efforts toward the employee segments with the highest attrition.
